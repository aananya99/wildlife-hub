## 🦁 Wildlife Hub
Wildlife Hub is a simple web application built with HTML,Tailwind CSS,DaisyUI, and JavaScript. It allows users to explore different animals,search by name,filter by categorys,sort alphabetically, and view detailed information about each animal.

### ✨Features 
- Search animals by name
- Filter animals by category 
- Sort animals (A-Z/Z-A)
- View animal details in a modal
- Responsive design 
- Debounced search for better performance

### 🛠 Technologies Used
- HTML5
- Tailwind CSS
- DaisyUI
- JavaScript(ES6)
